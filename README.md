# Prizm Geometry Dash
A playable port of Geometry Dash for the Casio Prizm fx-CG50. The project is currently unfinished, so there may be bugs and incomplete features. You can make your own levels with the online [level editor]("https://daniel86009.github.io/PrizmGD/LevelEditor/").

## Screenshots

## Features
- Play Geometry Dash directly on the Casio Prizm fx-CG50
- 6 built-in levels
- Custom level support
- Online level editor
- Play levels created with the level editor directly on the calculator

## Controls
- Arrow keys to navigate the menus
- Up arrow / EXE / Shift to jump (Whatever you prefer)
- Exit to pause

## Installation
- Download PrizmGD.g3a and GDLEVELS
- Connect your calculator to your computer via USB
- Copy the PrizmGD.g3a and GDLEVELS into the calculator's storage memory
- Disconnect the calculator and launch the application from the main menu

## Custom Levels
- You can create custom levels using the online [level editor]("https://daniel86009.github.io/PrizmGD/LevelEditor/").
- Use File -> Save as to save the level to your computer.
- To make changes later use File -> Open
- Copy level to GDLEVELS on your calculator
- they will appear in the level browser when you open the app
